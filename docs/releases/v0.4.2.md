## Install

CodeCity **0.4.2** is available as the standalone
[codecity-viewer npm package](https://www.npmjs.com/package/codecity-viewer).
With Node.js 22.13.0 or newer and npm installed:

```bash
npm install -g codecity-viewer@0.4.2
codecity /path/to/project
```

Or run without a global installation:

```bash
npx --yes --package=codecity-viewer@0.4.2 codecity /path/to/project
```

No Git installation, clone, or build is required. Git is optional for history
features. Source checkout commands are documented separately for development.
The optional installers can also set up Node when it is missing.

The VS Code extension is available on the
[Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=Amin-Tz.codecity).
For offline extension installation, download `codecity-0.4.2.vsix` below and use
**Extensions: Install from VSIX...** in VS Code.

## Changes

- Open the viewer while the initial scan continues, avoiding extension startup
  timeouts on large projects. Show analysis failures in the viewer.
- Limit JavaScript/TypeScript compiler analysis to 256 files / 4 MiB. Larger
  projects retain syntax metrics and local module references, with a warning
  explaining the analysis limit.
- Handle split UTF-8 startup messages, early process exits, and launch timeout
  cleanup. Reuse pending launches for the same folder and keep different project
  folders in separate sessions.
- Update the English and Persian installation docs to lead with the published
  npm package, identify 0.4.2 as the latest release, and separate development use.

See the [large-project investigation](https://github.com/Amin-Tgz/CodeCity/blob/v0.4.2/docs/LARGE_PROJECTS_0.4.2.md)
for recorded measurements and analysis limits.

macOS checks were still queued on GitHub at publication time and are not claimed
as verified for this release.

- `codecity-viewer.tgz`: packaged CLI and web viewer for installation with npm.
- `codecity-0.4.2.vsix`: self-contained VS Code extension.
- `install.ps1` / `install.sh`: optional installers, including Node setup.
- `uninstall.ps1` / `uninstall.sh`: removal of installer-managed installations.
