# CodeCity for Visual Studio Code

Explore your codebase as an interactive 3D code city directly inside VS Code.

## Features

- **Integrated 3D Tab**: View and navigate your project city inside a VS Code webview panel without leaving your editor.
- **External Browser Option**: Open in your preferred web browser whenever you want a dedicated window.
- **One-click Status Bar**: Launch instantly from the status bar item (`$(globe) CodeCity`).
- **Explorer Context Menu**: Right-click any folder in the File Explorer and choose **CodeCity: Open 3D View**.
- **Cross-platform**: Works seamlessly on Windows, Linux, and macOS.

## Installation from Release (.vsix)

1. Download the `codecity-0.4.0.vsix` file from the [GitHub Releases](https://github.com/Amin-Tgz/CodeCity/releases).
2. In VS Code, press `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS) and type:
   ```
   Extensions: Install from VSIX...
   ```
3. Select the downloaded `.vsix` file.

## راهنمای استفاده (فارسی)

- پس از نصب افزونه، دکمهٔ `CodeCity` در نوار وضعیت (پایین سمت راست) اضافه می‌شود.
- با کلیک روی آن یا کلیک‌راست روی هر پوشه در فایل اکسپلورر وی‌اس‌کد و انتخاب **CodeCity: Open 3D View**، شهر سه‌بعدی پروژه شما نمایش داده می‌شود.
- در بخش تنظیمات (`Settings -> CodeCity -> Target`) می‌توانید انتخاب کنید که شهر در تب داخلی وی‌اس‌کد باز شود یا در مرورگر پیش‌فرض سیستم‌عامل.
